# Por qué Strangler Fig es mejor que Big Bang Rewrite para el caso práctico

Strangler Fig permite, en el contexto de la migracion de un monolito hacia una nueva arquitectura, permite realizarlo en partes manejables o modulos que pueden se probadas y cambiadas (hacer switch), de manera que poco a poco se envie menos trafico al sistema legado, hasya el punto en donde ya no se use y el sistema se haya migrado completamente.
