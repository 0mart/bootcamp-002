# Por que el uso de Kong?

Las razones principales por las que las empresas lo eligen incluyen:
• Alto rendimiento y baja latencia: Está construido sobre Nginx y optimizado con LuaJIT, lo que le permite procesar decenas de miles de solicitudes por segundo con una sobrecarga mínima (menor a un milisegundo en muchos casos).
• Seguridad centralizada: Facilita la implementación de autenticación y autorización (como API Keys, JWT, OAuth 2.0 y OIDC) en un solo lugar, sin tener que programar estas validaciones en cada microservicio.
