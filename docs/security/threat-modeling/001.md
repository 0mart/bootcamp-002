# Modelado de amenazas con STRIDE

De acuerdo al analisis, el endpoint /api/v1/products/{id}

Cliente (desde internet) -> Kong Api Gateway (red interna) -> Microservicio products -> BD

- Spoofing (Suplantación)
Peticiones falsificadas pasando por alto el Gateway si el microservicio escucha en IP pública.

- Mitigación:
Red privada aislada; el microservicio solo acepta tráfico proveniente del API Gateway.
